# AI Response Comparator 

An interactive testing and evaluation framework designed to compare programming code generated by different AI models side-by-side. This tool acts as an automated quality guard by running code through syntax checks and isolated runtime assertion tests to expose hidden logic flaws (like broken recursive list slicing or faulty mutation tracking).

# Features
Interactive CLI Menu: Dynamically select distinct code profiles and test suites from a local registry.
* **Structural Syntax Audit:** Validates code compiling without executing messy or broken strings.
* **Isolated Runtime Sanboxing:** Safely executes generated functions inside independent local namespaces using `exec()`.
* **Functional Assertion Engine:** Runs real test cases against the AI's functions to confirm algorithmic accuracy.

## 🛠️ How It Works
1. Run the master script: `python comparator.py`
2. Select your algorithmic target profile from the console menu (e.g., `binary_search` or `bubble_sort`).
3. The harness prints out the raw output of each engine and logs whether it passes structural and functional testing thresholds.
